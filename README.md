# Troubadour для Cydia и Sileo

Клиент YouTube для iOS 5.1 и новее.

Источника два. Выбирайте по тому, нужны вам бета-сборки или нет.

**Только стабильные версии**

```
https://computershik73.github.io/repo/
```

**Стабильные и беты**

```
https://computershik73.github.io/repo/beta/
```

Во втором лежат и стабильные версии тоже, так что добавлять оба сразу
незачем — хватит одного.

Пакет в обоих источниках один и тот же, поэтому переход с бет
на стабильные и обратно — обычное обновление: удалять и ставить заново
ничего не нужно.

Беты — это сборки по мере правок. Они пишут подробный журнал
и выходят часто.
